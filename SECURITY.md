# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting for
[Bento-Browser/desktop](https://github.com/Bento-Browser/desktop): open the **Security** tab and
choose **Report a vulnerability**. Please do not open a public issue or pull request for a
suspected vulnerability.

Include the affected build or commit, reproduction steps, and the impact you observed.

## Supported versions

Bento Browser has no supported releases yet. Official releases stay private until v0.1.0.
Pre-v0.1.0 builds are unsigned maintainer builds. They receive no security
updates, and fixes land on `main` only.

Vulnerabilities in upstream Firefox or uBlock Origin that reproduce without Bento's changes
belong with those projects.
