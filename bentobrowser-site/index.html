Bento Browser

Workspaces. Panels. Privacy.
A Firefox-based browser, built for focus.

macOS Apple Silicon Windows x86_64

Developer preview. Builds are unsigned for now — on macOS, right-click the .dmg and choose Open the first time to bypass Gatekeeper. Code-signing and notarization land in a future release.

⊞

Workspaces

Group tabs by project, role, or mood. Switch with ⌘1–⌘9; each workspace remembers its tabs, its accent color, and the panels it had open.

▥

Bento Spaces

Open any tab as a side-by-side panel. Resize with a drag, reorder with another. The whole grid scrolls horizontally when you run out of width.

⌘

Command palette

⌘K opens a fuzzy search across tabs, workspaces, commands, and history. Get anywhere in the browser without leaving the keyboard.

⛨

Privacy by default

Telemetry, sponsored content, and Mozilla service promos are off out of the box. Tracking protection ships at strict. Live toggles in the in-app Privacy dashboard.

What is Bento, really?

Bento is derived from Mozilla Firefox — the same engine, web compatibility, same extension API. The chrome (UI shell) is rebuilt around workspaces and panels because the way browsers arrange tabs hasn't kept up with the way people actually work. It's open source under MPL-2.0; the source is on GitHub.
